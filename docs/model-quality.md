> 1. **20 页批次**（qwen3.8-27b 跑完 20 词条）：全流水线终审 20/20 + 4 组×5 页子代理逐条审校 + Mistborn (series) 单页精审；

> 铁律不变：不写正式站；写站仅 `Bot测试:` 前缀；引用不重排；宁保留英文不自造译名。

## 2. qwen3.8-27b 问题清单

### 2.1 结构类（门禁已覆盖=可拦）
- **ASCII 章节标题漏译**（最高频败因：8 页实验中 5 页标题类失败；20 页批次 5+ 处）：`== Notes ==`、`=== Trade ===`、`== Cover Gallery ==`、`==== Tormented by the Past ====`、`=== Scadrian Chapter ===`。中文章节标题（历史/注释）反而稳定。
- **标题闭合等号错**：`==== 历史 ===`、`==== 女士 ====n`（尾部混入字符，后者门禁未覆盖）。
- **括号断链**：历史上多起，但 2026-10-19 查明主因是**流水线 bug**（见 §5），模型侧真实例为纯链接列表字段 3 连败（合并/丢链）——已由 LINKLIST 占位机制根治。

### 2.2 半译类（结构可拦部分已拦；单词级=盲区）
- **整段"英文句架+中文专名"**：Waxillium 8 段（最危险发现，写站后才被审校发现；verify 3c 上线后可拦）。
- **句内单词级英文残词**：`capable`/`skilled`/`proficiency`/`distraction`/`simply`/`prestigious`——3c 按"行内≥6 叙述词"阈值结构性抓不到。

### 2.3 表内词"有表不查"（部分逃逸形态=门禁盲区）
- **正面成绩**：15/20 页零自造；非斜体裸词、信息框、链接显示等主要区域门禁终审 20/20。
- **逃逸形态**（历史教训，实验中复发过）：
  - 斜体内书名：`''Mistborn: The Final Empire''`/`''The Hero of Ages''` 等 11 词次（斜体=掩码豁免区）；
  - 全大写形态：奖项节 `*THE HERO OF AGES —`（裸词正则大小写敏感）；
  - 链接目标处：Ghostbloods 页 31 处 `[[Kelsier]]`/`[[Scadrial]]` 等英文目标（链接内豁免区）→ 中文站大面积红链；
  - 表内词当普通名词：`Mistborn→熔金术师`×4（表=迷雾之子）、`Clubs` 不译+"对俱乐部的恩惠"假友误译、`Lestibournes`、`First Union Bank`。

### 2.4 链接行为
- **过度链化**：Wax 净增 152 处内链（把普通名词链化：和谐×25、组织×14…）+ 自造红链 `[[无面不朽者的故乡]]`、`[[大枪]]`。
- **反向链化**：把表内词链成英文目标（见 2.3）。
- **丢链**：`[[Worldhopper]]` 被剥成裸词；脚注/正文反向不一致。
- 与 deepseek 对比：qwen 链接数普遍 >EN 源（convert 层 wob 展开 + 主动加链），ds 基本 ≈EN 源。

### 2.5 语义/流畅（门禁原理不可达，唯一防线=抽样审校）
- 译反：`prefer cravats to bowties`→"更喜欢领结而不是蝴蝶结"（领巾>领结 译反）；历史 3 例（foiled→失败、far more to her→对他而言、only decreased 方向类）。
- 病句/语序：`require extreme discipline that few Allomancers can achieve` 长定语错乱等。
- 旧译/错误译名复发：**伊兰黛尔市×8（应=依蓝戴）、公元纪年（应=灾变后/世纪）**——复发是批次级风险，提示词已加规则仍靠门禁兜不住（语义级）。

### 2.6 自造（表外）
- `《风暴档案》`（Stormlight Archive，非官译）、`血镕钉刺耳环`（把镕金混入血金）、`锡专家症`、`白蜡街帮`树种错位；导语自造书名「自我之影/自影」两度复发（`ensure_lead_title` 只兜结构、不核语义）。

### 2.7 qwen 的相对强项（不可丢）
- keep_en 名单项**从不越界**（对照 ds 违规 2 处）；引文块/`{{bws ref}}` 标题英文保留稳定；翻译完整度高（不吞内容）；译名贴表率高（多数页零自造）。

## 3. deepseek-v4-flash-0731 问题清单

### 3.1 结构/内容类（单点但重伤）
- **notice 吞句**：Ghostbloods 把"大量剧透"整句吞掉 + 首行 `'''鬼血会'''{{en|...}}` 标题行丢失、`{{en}}` 错位进 notice（对照实验中 ds 唯一 MAJOR 之一；门禁已拦 `{{en}}` 错位，**吞内容本身不可达**）。
- **括号断链**：Wax 与 qwen 逐字相同 = 流水线 bug（§5），非模型责任。
- `{{en}}` 挂载口径漂移：无 banner、`{{en}}` 挂导语（可渲染、门禁放行，但与既有页口径不一）。

### 3.2 保留名单/口径越界（门禁盲区）
- **keep_en 违规**：`Harmony's Sword→和谐的剑`、`Mistborn: Ghostbloods→迷雾之子：鬼血会`（qwen 正确保留）。
- **模板参数擅改**：`{{cat tag|Water body|Sea}}`→`海`（铁律"参数原样保留"）。
- **排版口径漂移**：`''斜体''`→《》书名号（与既有 `''[[X]]''` 口径冲突，连带改变斜体掩码行为）。
- 锚点中文化：`#Allomantic Use→#镕金术用途`（跨语言红锚风险）；`#泰瑞司统御区`。

### 3.3 表外批量自造（门禁盲区，ds 最大弱项）
- **历法 16 个月名整体音译**：莱尔/凯尔斯/多克希尔/哈姆达尔…（表外应保留英文）。
- 人名同页 2–3 写法且自造：穆里兹/玛拉兹/魅影、莎兰(32 处沙兰)、伊雅蒂/伊亚提尔、撒南忒/斯加阿纳特、达力拿/达利纳、乌理提鲁/乌理溯、娜瓦妮、萨依达卡、黑佩雷特（表=黑手佩瑞特）、`[[引信立方体]]` 红链、维夫火花补剂、迪西安·艾米安人。

### 3.4 表内失误
- `烈焰幸存者`（表内明令**勿用**，应=火焰幸存者，且与同页自相矛盾）、`白蜡日`（Pewter=白镴）、`Paalm→放血者`（表=帕尔姆）、`Constable-General→警长`（丢"总"）、`南方司卡德瑞尔人`（表=南方人）、`《迷雾之子：最后帝国》`（表=最后帝国(书籍)）、幸存者教会/德穆大道未译。

### 3.5 语义/流畅
- 方向词反译：`has only ever decreased→"只增不减地恶化"`（qwen 同处正确）。
- 语序欧化：`位于北[[蛮苦之地]]`、修饰范围含混句。
- 术语精度弱化：presumably→很可能（应=据推测）。

### 3.6 deepseek 的相对强项
- 标题基本全译（qwen 最大败因在 ds 不出现）；表内词内链 0 漏译（Ghostbloods 页）；正文完整度更高（3972 vs 3655 字符）；不主动加链（链接结构贴源）；门禁一次过 6-7/8。

## 5. 已修复的流水线问题（归因修正：括号类多为脚本责任）

1. **`_sub_glossary_in_string` finditer 偏移切片**（2026-10-19 修，commit 242ceb7）：裸词循环在 `finditer` 遍历中改写 `out`，同一词在一个值内多次命中时旧偏移落在已改短的字符串上 → 切出 `[[麦克斯利姆 Ladrian|Maxi麦克斯利姆[[…` 并吞掉 `]], `。**历史上多起"内链括号不配对"门禁失败实为此因，不应记在模型头上**（Wax 对照实验中两模型产物逐字相同是铁证）。修复=先收集区间再倒序应用；9/9 单测（形态/多次命中/短语保护/掩码/回填==原文/负例/幂等/多字段）+ 端到端验证（子嗣行完好、括号 418/418）。
2. **`_LINKLIST_LINE_RE` 只认 ASCII 字段名**（同 commit）：convert 已把 Infobox 参数名译中文（children→子嗣），掩码不命中导致纯链接值漏给 LLM。修复=字段名放开为任意非 `=` 字符，值形态仍严格限定纯链接列表；`=` 后空白收进组一保证逐字回填。
3. **`mask_nonprose` 换行塌陷**（更早）：多行模板掩码用等长空格替换吃掉 `\n` → 按行 zip 错位、误判整段。修复=掩码保留 `\n`（等长含行结构）。
4. **verify 误报史 3 起**（均已在流水线侧修复）：map ref 未合并前缀、file ref 未去竖线、keep_en 提示词失效裸词——教训：**门禁失败先分清"脚本 bug / 掩码错位 / 模型真错"再动模型侧**。
5. 归因纪律：任何"模型 3 连败同型"的问题，先做**同输入对照**（两模型是否逐字相同、发 LLM 前的中间产物是否已坏）。

## 6. 改进方向（按优先级）

### P0 —— 直接决定"一条命令跑对"与误伤率
1. **batch.py 自动重试闭环**：translate 失败（空块）/verify FAIL → 自动重跑该页最多 N 轮（可配 `--max-retry`），全绿才写。现状所有 retry 都是人工触发，这是"一条命令跑到绿"缺失的工程前提。
2. **标题门禁/预翻译去大小写敏感**：verify 3a 与 `_SECTION_HEADING_MAP` 查找统一小写归一；标题表按语料 data 派生扩容（含 Cover Gallery/Interior Art/Tormented by the Past/Trade 等长尾）。qwen 最大败因，一行改动收益最高。
3. **keep_en 合规门禁**（verify 新项）：keep_en 名单项在产物中被译出即 FAIL。ds 2 例实证必要；同时把 §4-2 的规则冲突（Trell）先裁决再实施。
4. **内链目标存在性门禁**：全部中文内链目标须命中 `zhwiki_titles` 清单（红链=FAIL），能同时抓：qwen 反向英文目标 31 处、两模型自造红链（引信立方体/无面不朽者的故乡）、锚点中文化的页面级兜底。

### P1 —— 质量上探（补盲区）
5. **词级英文残留**（此前评估"噪音大暂不做"，建议带词表重评）：剥掉链接/引文/代码后按词典过滤结构词，仅对"疑似叙述词"单数阈值≥1 报警——3c 的细化档。
6. **版式行覆盖**：`*` 奖项行、`!` 表头、`{{for}}` 参数、图注（`|caption=`）纳入半译扫描（掩码区分"决议保留英文的引文/出版块"与"应译版式"）。
7. **notice/导语完整性**：notice 模板参数与英文源关键片段（spoiler 类词）比对，吞句即 FAIL（ds Ghostbloods 型）。
8. **模板参数比对门禁**：`{{cat tag}}`/`{{map ref}}` 等结构模板的参数 token 与 convert 后源逐 token 对齐（ds 擅改 `Sea` 型）。
9. **表外自造监控**：产物 vs 英文源的内链目标集合 diff——新增目标未在表内即列"自造候选"进审校报告（不自动改写，守住"宁保留英文"）；配合"同页译名一致性"检查（多写法报警）。
10. **提示词定向**（qwen）：过度链化约束（仅译名表内词可新链、不得为普通名词造链）；"版式区也要译"显式条款。

### P2 —— 口径裁决（需用户拍板，勿擅自改）
- **Trell**：keep_en（`Trell (Trellism)`）与译名表（特雷）二选一或分场景。
- **幸存者教义 vs 幸存者教会**：管道显示忠实 vs 目标规范；中文站 `幸存者教义` 页缺失导致红链，需建页或改目标。
- **排版口径**：`''斜体''`（ds 用《》）——确定一种，写入提示词并加门禁。
- **历法月名/表外专名策略**：音译表一次性补全 vs 全部保留英文。
- 20 页批次遗留决策（Stormlight 8 组术语、Vindiel 音译入表、Sycamore 树种、盆地 3 地形名、生硬语序例）见 `state/qwen27b_report.md` §5/§6。

### 持续机制
- **每批 4 组×5 页抽样审校不可省**：语义反转、吞句、表外自造这三类是两模型共有的门禁不可达区，"零 review"在当前门禁下不成立。
- **模型选择参考**：价格敏感 + 接受更长回路 + 门禁/审校兜底 → qwen（P0+P1 补齐后回路会明显缩短）；交付时效优先、返工预算低 → deepseek（仍需 P0-3/4/7/8 补齐）。
