## 一、值域全集（从英文维基 16 基础金属 + 神金实测）

| 字段 | 取值集合 |
|---|---|
| `type-a`（镕金术表位·三元组）| 内外：`External`/`Internal`；推拉：`Pulling`/`Pushing`；分类：`Physical`/`Mental`/`Temporal`/`Enhancement` |

## 二、中译方案（含置信度）

### ✅ 高置信度（有中文维基权威依据）
| 英文 | 中译 | 依据 |
|---|---|---|
| `External` / `Internal` | 外部 / 内部 | 镕金术页 L68「按照内外分类，前者影响自身，后者影响外界」；正文「外部/内部」 |
| `Pulling` / `Pushing` | 拉 / 推 | 镕金术页「一种推，一种拉」；金属词条「推动/拉动」 |
| `Physical` | 肢体 | 镕金术 L68「肢体金属」；各金属词条「肢体力量/肢体类」 |
| `Mental` | 意志 | 镕金术 L60「外部意志力量」、L68「意志金属」（权威；金属词条误用「情感」）|
| `Temporal` | 时间 | 镕金术 L68「时间金属」；金属词条「时间类」 |
| `Enhancement` | 增强 | 镕金术 L68「增强金属」（权威；金属词条误用「强化」）|

### ⚠️ 中低置信度（中文维基本身不统一，需拍板）
| 英文 | 候选中译 | 争议 |
|---|---|---|
| `Cognitive`（藏金术 type-f）| 认知 | 中文维基三大界域里译「认知」/「知界域」两种都有；作为属性分类倾向「认知」 |
| `Spiritual`（藏金术 type-f / 血金术 type-h）| 灵性？/灵魂？/神瑛？| **最没把握**：中文维基对 Spiritual Realm 译「灵界域」（三界宙页）也译「灵魂」（界域论页）；且「神瑛」在中文维基专指「持碎瑛之力的存在」（Shard 译「碎瑛」），Spiritual 属性 ≠ 神瑛。作金属属性分类，倾向「灵性」 |
| `Hybrid`（藏金术 type-f）| 混合 | 较稳，但中文维基未见该语境直接用例 |

## 三、中文 info box 与英文 type-a 的差异总结（用户第 4 步）

### 硬错误（语义错）
- **白镴（Pewter）**：中文 info box 填「内外=**外**」；英文 `type-a = Internal, Pushing, Physical` = **内部**、推、肢体 → **应为「内」**。其余 15 个基础金属的推拉/内外方向**均正确**。

### 软问题（语义方向对，但用词与权威设定不统一）
分类字段目前三种写法并存：
| 现填 | 权威（镕金术 L68）| 涉及的金属 |
|---|---|---|
| 「肢体力量」| 肢体 | 铁/钢/锡/白镴 |
| 「情感」| **意志** | 锌/黄铜/红铜/青铜 |
| 「强化」| **增强** | 铬/镍铬/铝/硬铝 |
| 「时间」| 时间 ✅ | 镉/弯管/金/电金 |

> 即金属词条正文首句（如锌「拉动外部情感」、镍铬「强化类」）与镕金术页面权威分类表述（「肢体/意志/增强/时间」）用词**不一致**。统一口径后应为：**肢体/意志/增强/时间**。
